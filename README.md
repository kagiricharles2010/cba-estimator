# CBA 2025–2029 pay estimator (demo)

A one-page calculator that helps academic staff in Kenyan public universities estimate their pay under the 2025–2029 CBA. It covers new basic salary, arrears and take-home pay, using the schedules in the Return to Work Formula of 30 October 2026.

**Live page:** https://kagiricharles2010.github.io/cba-estimator/

**Unofficial demo.** This tool hasn't been certified or endorsed by UASU, IPUCCF, FKE, the Ministry of Education, KRA or any other body. The figures are estimates only.

All calculations run in the visitor's browser. Nothing is stored or sent anywhere.

## Updating
Replace `index.html` with the new version and commit. GitHub Pages republishes it within a minute or two.
